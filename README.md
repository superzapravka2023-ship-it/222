# 🤖 Bybit Short Hunter Bot

Telegram-бот для мониторинга фьючерсов Bybit.  
Находит монеты, которые резко выросли — сигналы для входа в шорт.

## ⚙️ Как работает

1. Каждые **5 минут** сканирует ВСЕ USDT-фьючерсы Bybit (500+ монет)
2. Находит монеты с ростом **50%+** за период от 1 до 36 часов
3. Добавляет в **Watchlist** и продолжает следить
4. Когда монета достигает **80–90%** роста — отправляет алерт 🎯
5. Это сигнал для входа в **ШОРТ** 📉

## 🚀 Деплой на Render

### 1. Создай Telegram-бота
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. `/newbot` → введи название → получи **TELEGRAM_TOKEN**
3. Узнай свой Chat ID через [@userinfobot](https://t.me/userinfobot) → **TELEGRAM_CHAT_ID**

### 2. Загрузи на GitHub
1. Создай новый репозиторий на GitHub
2. Загрузи все файлы из ZIP-архива

### 3. Настрой Render
1. Зайди на [render.com](https://render.com) → New → Blueprint
2. Подключи свой GitHub репозиторий
3. Render автоматически прочитает `render.yaml`
4. В разделе **Environment Variables** добавь:

| Переменная | Значение |
|------------|----------|
| `TELEGRAM_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | твой числовой ID |

5. Нажми **Deploy** ✅

## 📱 Команды бота

- `/start` — главное меню
- `/set min_tf 1` — мин. таймфрейм в часах (по умолч: 1)
- `/set max_tf 36` — макс. таймфрейм в часах (по умолч: 36)
- `/set min_pct 50` — мин. % роста для алерта (по умолч: 50)
- `/set target_pct 80` — % роста для сигнала шорта (по умолч: 80)
